# Verification Tests

These are workflow verification tests generated by the `verify-workflow` pipeline. They exercise the
attach-a-file-and-get-an-AI-description-or-OCR flow (📎 file picker, drag-and-drop, copy-paste) for both
the project agent (`/[project]/agent`) and the main/assistant agent (`/assistant`), against a real,
running `trayline-server` backend — no mocked API calls or agent responses.

## Running

The application must be running locally first:

```bash
PUBLIC_API_URL=http://trayline-server:9000 npm run dev -- --host 0.0.0.0 --port 5173
```

Then, from `dashboard/`:

```bash
npx playwright test e2e/verification/
```

Agent replies stream from a real LLM in a spawned container, so individual tests can take up to ~120s.
